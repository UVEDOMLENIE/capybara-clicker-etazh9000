## 🟣 О чём это

Ты — невидимый ИП на ЭТАЖЕ 9000. Тут живут капибары: кодят, пьют кофе, ходят на стендап.
**Тапай главную капибару** → копи **КАПИКОИНЫ (КК)** → нанимай команду → она зарабатывает сама.

## 📱 Главное в v0.4.0 — мобилка

Игра переписана под телефон (в первую очередь iPhone):

- **Один экран, без скролла страницы.** Сверху HUD, в центре капибара, снизу магазин.
- **Свайп вниз** (или клик по ручке вверху) → выезжает **шторка настроек**: скины, рекорд,
  достижения, статистика, звук/вибро/анимации, помощь, сброс. Раньше всё это было «под капибарой»
  и на телефоне не доскролливалось — теперь живёт в шторке.
- Тач без задержек (`pointerdown`, `touch-action`), safe-area под чёлку, `100dvh`,
  haptic-отклик (вибро) на тапы и покупки.
- На компе всё тоже работает: настройки открываются **кликом** по ручке, свайпом мышью или **Esc**.

## 🎮 Как играть

1. **Тапай капибару** по центру — капают КК.
2. В магазине внизу **нанимай команду** — она даёт КК/сек.
3. Каждые **10 / 25 / 50 / 100…** одинаковых работников их доход **×2** (майлстоуны) — бери массово.
4. Держи **комбо** (тапай без пауз) — до ×3 к тапу.
5. Лови **🦫✨ золотую капибару** — пролетает по экрану, даёт жирный бонус (монеты или ×7 баф).
6. Иногда прилетает **СОБЫТИЕ** (мини-игра на пару секунд) за бонус.
7. Накопил много — жми **ПРЕСТИЖ**: сгораешь ради вечного множителя (кринж-очки).

| Действие | Телефон | Комп |
|---|---|---|
| Тап капибары | палец | ЛКМ / `Space` |
| Настройки | **свайп вниз** | клик по ручке / свайп / выход — `Esc` |
| DJ-мини-игра | тап по A S D F | клавиши `A S D F` |

## ⚖️ Баланс (что переосмыслено)

Старая боль: «накликал мало, а ценники в лямах» + «в эндгейме тапать бессмысленно».

- **Тап = плоская мощь + % от КК/сек.** Поэтому тапать выгодно ВСЮ игру, а не только в начале.
- Старт удешевлён (джун 15→10, кофеварка 100→60), удорожание мягче (×1.18 → ×1.15).
- **Майлстоуны ×2** за 10/25/50/100… работников — понятная цель «добить до порога».
- Криты до ×7, комбо до ×3, оффлайн-доход 55% (до 8 ч).
- **Престиж в кринж-очках**: `√(всего КК / 1М)`, каждое очко = +10% навсегда. Понятно и наглядно.

## ✂️ Что убрали (нелогичное/лишнее)

- ❌ **Фейк-лидерборд с ботами** — владелец прямо сказал «генерёнка нахер не нужна».
  Заменён на **личный рекорд** (он вернётся как онлайн-таблица, когда будет сервер).
- ❌ **Чит-гэг «обнаружен вибратор»** — не для аудитории «детям 12 балдёжно».
  Заменён на **золотую капибару** — та же «движуха», но позитивная.
- ❌ Десктопные 3 колонки, тонна панелей вокруг поля — всё уехало в шторку.

## 🧰 Стек

Чистый **vanilla HTML + CSS + JS**, без сборки и зависимостей. Звук — **Web Audio API** (синтез,
без mp3). Капибара — **inline-SVG** (80 скинов: 5 тел × 4 шапки × 4 акса). Сейв — **localStorage**.

```
capybara-rescue/
├─ index.html   ← разметка: HUD / play / shop + шторка настроек
├─ style.css    ← мобайл-фёрст кринж (радуга, Comic Sans, неон)
├─ game.js      ← вся логика: тап, экономика, эвенты, золотая капибара, свайп-шторка
├─ README.md    ← этот файл
├─ DEVLOG.md    ← рабочий журнал (для меня и для тебя)
├─ ARCHITECTURE.md
└─ wiki/        ← зал славы + changelog по версиям
```

## 🚀 Запуск

Двойной клик по `index.html`. Или локальный сервер:

```bash
python -m http.server 8080   # → http://localhost:8080
```

## 💾 Сейвы

`localStorage`, ключ `DEVIN_MEGA_CAPYBARA_v1`. Сброс — в шторке настроек кнопкой «🗑 Сбросить прогресс».
Старые сейвы v0.3.0 подхватываются (миграция через `{...DEFAULT_STATE(), ...saved}`).
