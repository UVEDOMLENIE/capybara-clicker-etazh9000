Этаж функционирует на основе **трёх стихий**:
- 🦫 **Капибары** (рабочая сила, 1.0 ECU/каждая в режиме idle).
- ☕ **Кофе** (топливо, расход ~1.4 чашки на капибару в минуту).
- 🍜 **Доширак** (стратегический резерв на случай внепланового релиза).

**Принципы:**

- **No build step.** Никакого Webpack. Если у тебя нет Node.js — игра всё равно работает.
- **No backend.** Сервер не нужен, потому что капибары не доверяют облакам.
- **No telemetry.** Аналитика осталась на этаже 8999.
- **Idempotent saves.** Состояние сериализуется в JSON, ключ `DEVIN_MEGA_CAPYBARA_v1`.

## 3. GameState (одна правда, один объект)

Всё игровое состояние живёт в одном глобальном объекте `S`:

```js
S = {
  coins: number,         // текущие капикоины
  totalCoins: number,    // всего нашлёпано за этот цикл (для престижа)
  clicks: number,        // суммарное количество шлепков
  events: number,        // выжито мини-игр
  standups: number,      // сколько раз догоняли стендапом
  clickPower: number,    // базовая мощность шлепка
  multiplier: number,    // множитель от MEGA-апгрейдов
  prestige: number,      // количество циклов престижа
  prestigeMult: number,  // вечный множитель от престижа
  combo: number,         // текущее комбо (сбрасывается через 2.4с)
  workers: { id: count }, // нанятые рабочие
  upgrades: { id: bool }, // купленные апгрейды
  achievements: { id: bool }, // открытые ачивки
  muted: bool,           // звук
  lastSeen: number,      // timestamp для оффлайн-дохода
}
```

При закрытии вкладки и каждые 4 секунды объект сериализуется и пишется
в `localStorage`. Никаких миграций, никаких Postgres.

## 4. Игровой цикл (40 ticks/сек)

```
       ┌────────────────────────────────┐
       │      requestAnimationFrame     │
       └─────────────┬──────────────────┘
                     │ dt
                     ▼
           ┌───────────────────────┐
           │ if (!event.active)    │
           │   coins += cps * dt   │
           └─────────────┬─────────┘
                         ▼
              ┌─────────────────────┐
              │  checkAchievements  │
              └─────────┬───────────┘
                        ▼
              ┌─────────────────────┐
              │      updateUI       │
              └─────────┬───────────┘
                        ▼
              ┌─────────────────────┐
              │    spawnSparkle()   │  (с вероятностью 6%)
              └─────────────────────┘
```

Параллельно работает `eventLoop()` — раз в 28-60 секунд бросает кубик и
запускает один из 5 типов рандомных эвентов.

## 5. Рандомные эвенты (мини-игры внутри игры)

| Эвент       | Длит. | Механика                                          | Награда         |
|-------------|------:|---------------------------------------------------|-----------------|
| 🐞 BUG       | 8 с   | Кликай по жукам, появляющимся в случайных точках | × число пойманных |
| 🎧 DJ        | 9 с   | Падают ноты, лови их `A S D F`                   | × score        |
| 🏃 STANDUP   | 6 с   | 30 кликов по убегающей капибаре                  | большой бонус   |
| ☕ COFFEE    | 6 с   | Просто наблюдаешь. x2 КК/сек на 6 сек            | гарантирован    |
| 🌈 CRINGE    | 8 с   | Лотерея на 4 капибар: x0.5 / x1 / x5 / x20       | случайная       |

Все эвенты используют **общий слой** `#event-layer` (поверх сцены),
который перехватывает клики на главную капибару, чтобы юзер не путался.

## 6. Звуковая подсистема

**Web Audio API** — без файлов, без задержек, без тонны MP3.
Все звуки — это `OscillatorNode + GainNode + быстрая огибающая`:

```js
function beep({ f, t, type, vol, slide }) {
  // короткий sine/square/triangle/sawtooth с экспоненциальным затуханием
}
```

Из этого собраны:
- `sfxClick()` — короткий блип со слайдом частоты вверх.
- `sfxCoin()` — два чистых тона (классика jingle на покупке).
- `sfxBuy()`  — sawtooth-аккорд для апгрейдов.
- `sfxAch()`  — арпеджио из 4 нот (мажорное).
- `sfxAlarm()` — 4 нисходящих сирены для эвентов.
- `sfxPrestige()` — длинная восходящая лестница из 6 нот.

> ⚠️ **Браузеры запрещают AudioContext до первого пользовательского жеста.**
> Поэтому `audioCtx` создаётся лениво при первом клике/нажатии.

## 7. Капибара (визуальный компонент)

Капибара нарисована **inline-SVG** прямо в `index.html` примитивами:
2× ellipse (тело + голова), 2× ellipse (ноги), 2× ellipse (уши),
1× circle (глаз), 1× ellipse (нос), 1× path (рот), 2× rect (зубы).

**Анимации:**
- `capyIdle` — медленное покачивание (1.6 с).
- `capySquish` — мгновенное сжатие при клике (0.12 с).
- `discoCapy` — hue-rotate 0→360° за 0.4 с (включается каждые 25 кликов).
- `bob` + `spin` — для логотипа в шапке.

Тень — отдельный div с `filter: blur(6px)` и пульсирующим scaleX.

## 8. CSS-кринж (намеренно)

В `style.css` использовано:
- `Comic Sans MS` как `font-family` всего интерфейса.
- `<marquee>`-эффект через `@keyframes` + `transform: translateX(-50%)`.
- `radial-gradient` × 4 на фоне + анимированный `hue-rotate`.
- `mix-blend-mode: difference` для psy-overlay во время кринж-волны.
- Кастомный курсор — inline-SVG капибары через `data:image/svg+xml`.
- Радужный текст через `background-clip: text` + двигающийся градиент.
- `animation: blinker 0.6s steps(2)` — старая школа, как в браузерах из 2002.

## 9. Сохранения и оффлайн-доход

Каждые 4 секунды и при `beforeunload` состояние сериализуется в localStorage.
При запуске игра считает разницу между `Date.now()` и `S.lastSeen`:
- если прошло > 30 секунд — начисляется оффлайн-доход за время отсутствия,
- но не больше 2 часов и со штрафом × 0.4 (капибары спят).

## 10. Безопасность и приватность

- **Никаких внешних запросов.** Игра работает офлайн.
- **Никакого fingerprint.** Только localStorage.
- **Никакого «согласитесь с куки».** Куки тут даже не пахнет.
- **Никаких аналитик.** Капибары следят только за тимлидом.

## 11. Известные ограничения и долги

- 🟡 Звуки могут запинаться на старых ноутбуках с встроенной звуковой картой.
- 🟡 На экранах < 600 px интерфейс становится скроллящимся, но играбельным.
- 🟡 На айфонах с включённым «Reduce Motion» некоторые анимации отключатся —
  CSS соблюдает `prefers-reduced-motion` через дефолтные правила браузера.
- 🔴 Сингулярность не учтена в моделях климата ООН.
