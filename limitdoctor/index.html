Если не знаешь, что такое Claude Code

Лимит — как баланс на телефоне

Claude Code — ИИ-программист по подписке, и у подписки есть лимит. Тариф знаешь, а куда ушёл лимит — нет. LimitDoctor показывает детализацию: какой чат сколько съел и на какой модели.

Самые дорогие чаты

Цвет — модель. Справа — сколько чат съел лимита за неделю. В отчёте по клику открывается чат.
Главная фишка

Тот же чат — на каждой модели

Каждый чат пересчитан на Haiku, Sonnet, Opus и Fable по тем же вызовам. Кольцо — сколько съел на самом деле. Сразу видно, где сильная модель избыточна.

HaikuSonnetOpusFableкак было
Чем дальше точки друг от друга, тем сильнее модель меняет цену чата. Справа — % лимита за неделю.
Каждый чат под микроскопом

Дашборд вызовов

Каждый столбик — один вызов модели: прочитала переписку и ответила. Выше — дороже. Быстрое, простое понимание структуры расходов по каждому чату. Наведи на столбик.

Своя единица измерения

Хайку-токены

Модели стоят по-разному, кэш в десятки раз дешевле, effort раздувает мысли. Мы свели всё в одну валюту — теперь Fable и Haiku меряются на одной линейке.

1 ХТ
= один входной токен Haiku = $1 за миллион
Один токен ответа стоит:
Haiku5ХТ
Sonnet10ХТ
Opus20ХТ
Fable50ХТ
Перечитать переписку из кэша — 0,1–0,25 ХТ за токен. Записать заново — в 12–20 раз дороже.
Кто и когда жрёт лимит

Когда горит лимит

День недели × час, в среднем за неделю. Чем ярче клетка, тем больше лимита сгорело. В отчёте при наведении — какие чаты жрали в этот час.
