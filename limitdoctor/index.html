Если не знаешь, что такое Claude Code

Лимит — как баланс на телефоне

Claude Code — ИИ-программист по подписке. У подписки есть лимит: сколько можно наработать за 5 часов и за неделю. Тариф ты знаешь, а куда ушёл лимит — нет: какой чат, какая модель, какой вызов. LimitDoctor — та самая детализация.

Кто и когда жрёт лимит

Когда горит лимит

День недели × час. Чем ярче клетка, тем больше лимита сгорело. Наведи в отчёте — увидишь, какие чаты жрали в этот час.

Детализация

Расход по дням

Цвет — модель, пунктир — дневная норма (неделя ÷ 7). Видно, в какой день улетела треть недели.

Анатомия расхода

Куда ушли токены

Почти половина — обвязка: инструкции, инструменты и скиллы, которые модель перечитывает в каждом вызове. Её видно только здесь.
